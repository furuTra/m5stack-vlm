# 日報作成タスク

以下の手順で今日の作業内容をNotionに記録してください。

## 1. 作業内容の収集

- `git log --since="6am" --oneline --all` で今日のコミット履歴を確認する
- `git diff HEAD~$(git log --since="6am" --oneline | wc -l) --stat` で変更ファイルの概要を確認する
- このセッション中で行った作業（設計判断・調査・試行錯誤・保留にした事項）も合わせて振り返る

## 2. 日報の構成

以下の形式でまとめる（過不足があれば柔軟に調整してよい）：

- **日付**: 今日の日付
- **プロジェクト**: 対象プロジェクト名
- **やったこと**: 箇条書きで3〜7項目程度。「〇〇を実装」「△△のバグを修正」など具体的に
- **決定事項とその理由**: 設計判断をした場合はその理由も記録（後でナレッジ化する際の材料になる）
- **保留・未解決事項**: 次回に持ち越す課題
- **次にやること**: 次回セッションの入り口になる短いメモ

## 3. Notionへの記録

Notion MCPの `search` ツールで「Claude日報」という名前のデータベースを探す。
（見つからない場合は、ユーザーにデータベース名や場所を確認する。名前が変わっている可能性もある）
見つかったら `create-pages` でその日のエントリを1ページとして追加する。
プロパティには少なくとも「日付」「プロジェクト」「タグ」を設定する。

## 4. 完了報告

Notionに記録したページのURLを最後にユーザーに提示する。
