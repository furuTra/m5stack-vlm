# ナレッジ抽出タスク

日報の山から、後で参照する価値のある知見だけを抽出してナレッジベースを更新してください。
これは日報とは別の「精製された」ドキュメントです。日報の要約の繰り返しにならないよう注意する。

## 1. 対象期間の日報を収集

Notion MCPの `search` / `fetch` で「Claude日報」データベースから、指定期間（デフォルトは直近1〜2週間、ユーザー指定があればそれに従う）の日報エントリをすべて取得する。

## 2. パターンの抽出

日報群を横断して、以下の観点で共通点や繰り返しを探す：

- **繰り返し詰まったポイント**: 同じ種類のバグ・設計ミスが複数回出ていないか
- **有効だった設計判断**: 後から見ても「これは良い選択だった」と言える決定とその理由
- **今後のプロジェクトに使い回せる知見**: 特定プロジェクトに閉じない、一般化できるノウハウ
- **保留のまま放置されている課題**: 複数回「次にやること」に出てきているのに解決していない項目

ログの要約ではなく、蒸留された洞察を書くこと。「〇月〇日に何をした」ではなく「〇〇という状況では△△が有効/危険」という形にする。

## 3. ナレッジページへの反映

既存のナレッジページ（プロジェクトごと、またはテーマごと）をNotionで検索し：

- 既存ページがあれば `update-page` で該当セクションを追記・更新
- なければ `create-pages` で新規作成し、後から検索しやすいタイトル・タグを付ける

## 4. 完了報告

更新したページのURLと、抽出した知見の要点を3〜5行でユーザーに提示する。
